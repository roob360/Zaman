# Roadmap

| Tahap | Isi | Status |
|---|---|---|
| V0 | Waktu per musim (tanggal, kecepatan, musim menurut lintang) | Selesai |
| V1 sampai V5 | Dunia hidup (sprite, rumah satu per satu, ladang), fauna, perang terlihat, efek alat dewa dan bencana, palet kekuatan dewa ala WorldBox | Direncanakan |
| A2 | Tingkatan permukiman, bentuk negara, ideologi, gelar pemimpin | Direncanakan |
| A | Inti simulasi, UI macOS 27 adaptif, alat dewa, simpan/muat, PWA, publikasi GitHub Pages | Berjalan (inti selesai, Worker selesai, UI berikutnya) |
| B | Bencana alam berbasis sebab: deforestasi dinamis, patahan dan tegangan, gunung api, banjir, longsor, kekeringan, kebakaran, gempa, tsunami, letusan, pemanasan. Overlay bahaya, pemicu dewa | Belum |
| C | Kepercayaan/agama yang muncul sendiri: pendiri karismatik saat krisis, penyebaran lewat kontak sosial, pedagang, pemimpin, penaklukan. Efek pada kepuasan, perang, pengetahuan, perpecahan | Belum |
| D | Mode uji berulang: banyak run per skenario, peluang bertahan, rata-rata tahun era modern, tabel perbandingan | Belum |
